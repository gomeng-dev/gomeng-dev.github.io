돚거콘 개인정보처리방침

운영자: gomeng-dev
시행일: 2026년 11월 3일

1. 적용 범위와 문의

gomeng-dev는 Android 앱 돚거콘과 이 방침을 제공하는 웹페이지를 운영합니다. 앱 자체 회원가입은 제공하지 않습니다. 개인정보 관련 문의와 열람·정정·삭제·처리정지 요청은 gomeng-dev@protonmail.com으로 보내주세요.

2. 기기 안에서 처리하는 정보

선택하거나 수집한 이모티콘의 원본·미리보기, 세트 이름과 출처 URL, 즐겨찾기·최근 사용·정렬·숨김, 사용할 앱 선택과 기타 설정을 기기에 저장합니다. 이 보관함을 개발자의 서버로 업로드하거나 기기 간 자동 동기화하지 않습니다. 앱 선택 화면을 제공하기 위해 설치된 실행 가능 앱의 이름·패키지명·아이콘을 기기에서 확인하며, 설치 앱 목록과 선택 목록을 사용 분석으로 보내지 않습니다.

0.9.4 이상에서는 플로팅 팝업에서 이모티콘을 고르면 사용자가 선택한 앱의 입력창에 이미지 전달용 입력기를 통해 이미지와 필요한 읽기 권한을 직접 전달하며, 시스템 클립보드로 자동 복사하지 않습니다. 보관함의 ‘복사’를 직접 선택했을 때는 시스템 클립보드에 이미지를 복사합니다. 이전 버전의 플로팅 팝업도 클립보드를 사용할 수 있습니다. 수신 앱에 저장되거나 전송된 사본에는 해당 앱의 정책이 적용됩니다. 클립보드는 자동으로 지우지 않으며 시스템·키보드의 클립보드에 남을 수 있습니다.

3. 접근성과 이미지 전달용 입력기

사용자가 별도로 동의하고 연결한 접근성 기능은 현재 앱과 입력창의 활성 상태·위치·터치를 확인해 버튼을 표시하고, 사용자가 직접 고른 이미지를 전달할 때 이미지 입력기로 잠깐 전환하는 데 사용합니다. 대화·입력 문장을 분석·저장·전송하거나 메시지 전송 버튼을 누르지 않습니다.

Android 11 이상에서 사용자가 별도로 연결하는 임시 이미지 전달용 입력기는 선택한 모든 대상 앱에 이미지 직접 입력을 요청하고 기존 키보드로 돌아가는 용도입니다. 지원하지 않는 입력창에서는 전달을 중단하며 클립보드 붙여넣기로 자동 전환하지 않습니다. 일반 문장을 입력하는 키보드를 대체하지 않으며 키 입력을 분석 정보로 수집하지 않습니다. 접근성·입력기는 Android 설정에서 해제할 수 있고, 사용 분석 동의와는 별도입니다.

4. 커뮤니티 웹뷰와 이미지 수집

사용자가 URL을 열거나 이모티콘을 수집하면 해당 커뮤니티·이미지 제공 서버로 요청을 보냅니다. 이 과정에서 외부 서버는 IP 주소, 브라우저 정보, 요청 주소와 필요한 쿠키·로그인 세션·참조 페이지 정보를 처리할 수 있습니다. 웹뷰 쿠키와 세션은 기기에서 관리하며, 외부 사이트에 입력하는 로그인 정보와 그 사이트의 광고·분석에는 해당 사이트의 방침이 적용됩니다.

웹뷰의 로그인 폼, 비밀번호, 쿠키, 원본 URL·서명 매개변수와 이미지 내용은 돚거콘의 사용 분석으로 보내지 않습니다.

5. 선택적 사용 분석

기본적으로 분석 수집은 꺼져 있습니다. 사용자가 허용하면 Firebase Analytics·Google Analytics 4를 이용해 기능 이용과 오류 경향, 대략적인 이용 지역 및 정상 구매 현황을 분석하여 앱을 개선합니다. 처리 항목은 다음과 같습니다.

  • 앱 열기·세션·화면과 기능 이용, 수집 사이트 구분과 성공·실패·중복 개수, 결제 흐름의 결과 종류
  • 앱 버전, 운영체제·기기 모델·언어 등 기술 정보, 가명 앱 인스턴스 식별자
  • IP에서 도출한 국가·지역·도시 등 근사 위치, 프리미엄 이용 상태 및 정상 구매 시 상품·금액·통화 등 구매 측정 정보

GPS나 정확한 위치 권한을 사용하지 않습니다. Google은 IP를 근사 위치 산출과 기본 서비스·스팸 방지에 사용하고, 원시 IP를 사용자 식별자와 연결하지 않으며 사용 후 삭제한다고 안내합니다. 근사 위치는 실제 위치나 국적을 확정하는 정보가 아닙니다.

대화·입력 문장·키 입력, 비밀번호, 웹뷰 폼·쿠키, URL, 개인 미디어, 이모티콘·세트 이름, 설치 앱 목록, 구매 토큰은 분석 이벤트에 넣지 않습니다. 앱에는 광고나 광고 SDK가 없으며, 광고 ID 수집과 광고 개인화를 사용하지 않습니다.

설정의 ‘사용 분석 허용’에서 언제든 거부하거나 철회할 수 있습니다. 거부해도 이모티콘 사용과 정상 구매 기능을 이용할 수 있습니다. 철회는 이후 분석 수집을 중단하는 선택이며 과거 서버 자료를 즉시 모두 삭제하는 동작은 아닙니다.

6. Google Play 결제

세트 무제한의 일회 구매·구매 상태 조회·복원을 위해 상품 ID, 구매 상태·거래 정보, 구매 토큰과 서명 등 권한 확인에 필요한 정보를 앱과 Google Play에서 처리합니다. 앱은 구매 확인 정보를 기기에 보관해 세트 자동 숨김 제한 해제와 복원에 사용합니다. 결제수단 번호를 앱이 직접 입력받거나 보관하지 않으며 구매 토큰을 사용 분석으로 보내지 않습니다.

7. 외부 처리와 국외 인프라

분석을 허용하면 위 분석 정보가 네트워크를 통해 Google(Firebase·Google Analytics)에 전송됩니다. Google Play는 앱의 상품·구매 상태 조회와 결제·복원 과정에 필요한 정보를 처리합니다. 이들 서비스의 정보는 미국 등 Google과 관련 처리업체의 시설이 있는 국외에서 처리·보관될 수 있으며 대한민국 내 보관으로 한정되지 않습니다. 실제 처리 위치는 서비스와 인프라에 따라 달라집니다. 자세한 내용과 연락 경로는 Firebase의 처리 위치 안내와 Google 개인정보처리방침을 확인해주세요. 분석의 국외 처리를 원하지 않으면 사용 분석을 허용하지 않거나 설정에서 철회할 수 있습니다.

이 방침과 이용약관 웹페이지는 GitHub Pages로 제공합니다. 페이지에 별도의 광고·분석 스크립트를 넣지 않지만, GitHub는 로그인 여부와 관계없이 방문자의 IP 주소를 보안 목적으로 기록·저장합니다. 페이지 접속에 따른 통신·방문 정보는 GitHub의 호스팅·보안 정책에 따라 미국 등 국외에서 처리될 수 있고, 앱의 분석 허용 설정과는 별개입니다. GitHub Pages 데이터 수집 안내와 GitHub 개인정보처리방침에서 보관·권리 행사 방법을 확인할 수 있습니다.

8. 보관과 삭제

기기 보관함은 사용자가 이모티콘·세트를 삭제하면 해당 항목을 정리합니다. Android의 앱 데이터 삭제나 앱 제거로 기기 내 앱 데이터와 웹뷰 세션을 정리할 수 있습니다. 다른 앱으로 전달한 사본, 외부 사이트 계정·서버 기록과 Google Play의 구매 기록은 별도로 관리되므로 함께 삭제되지 않습니다.

사용 분석 속성의 보관 설정은 이벤트 데이터 2개월, 사용자 데이터 14개월이며 새 활동 발생 시 사용자 데이터 보관 기간을 재설정합니다. 따라서 계속 이용하면 사용자 데이터의 만료 시점도 갱신될 수 있습니다. 대상 데이터는 보관 기간 종료 후 Google의 월별 삭제 처리에 따릅니다. 이 설정은 표준 집계 보고서나 Google Play의 거래 기록 전체에 같은 삭제 기한을 부여하는 것은 아닙니다. Google의 보관 안내를 참고해주세요.

서버에 남은 본인 분석 정보의 삭제는 문의 주소로 요청할 수 있습니다. 앱에는 로그인 계정이나 이메일과 분석 식별자를 연결하는 기능이 없어 이메일 주소만으로 해당 기록을 찾기 어려울 수 있습니다. 대상 식별자를 확인할 수 있는 경우 Google의 사용자 데이터 삭제 절차를 이용하며, 확인이 어렵거나 처리 범위에 제한이 있으면 이유와 가능한 방법을 안내합니다. 분석 철회·앱 제거만으로 과거 서버 기록이나 집계 자료가 모두 즉시 삭제된다고 보장하지 않습니다.

문의하면 이메일 주소, 문의 내용과 사용자가 첨부한 정보를 답변·문제 해결에 사용합니다. 목적을 달성한 정보는 지체 없이 삭제하며 법령상 보존이나 분쟁 대응에 필요한 정보는 해당 사유와 필요한 기간 동안 별도로 보관합니다. 비밀번호, 구매 토큰이나 전체 결제수단 번호는 보내지 마세요.

9. 보호 조치와 방침 변경

앱 내부 파일과 이미지 읽기 권한을 필요한 범위로 제한하고 네트워크 통신에는 HTTPS를 사용합니다. 개인정보 관련 요청에는 대상과 요청 권한 확인에 필요한 최소 정보만 확인합니다. 중요한 처리 내용이 달라지면 이 페이지나 앱의 안내를 통해 변경 내용과 시행일을 알립니다.
