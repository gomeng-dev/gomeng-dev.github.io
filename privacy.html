운영자: gomeng-dev · 시행일: 2026년 10월 13일

이 방침은 Android 앱 이지 비디오 다운로더(io.gomeng.easydownloader)와 이 안내 웹사이트에서 정보를 처리하는 방식을 설명합니다.

방문·다운로드 내역은 기기에 보관합니다. 동의 없이 운영자에게 이 내역을 전송하지 않습니다. 이용자가 선택한 실패 URL 제보와 별도 동의한 앱 사용 통계는 아래와 같이 처리합니다. 광고·결제, 사용자가 접속한 웹사이트 및 선택한 저장소에서는 아래에 설명한 정보 처리가 이루어집니다.

일반 방문·다운로드 목록은 전송하지 않습니다. 외부 설문에서 직접 제출한 내용 또는 앱에서 개별 제보·자동 제보에 동의한 실패 URL과 진단 항목은 문제 조사와 기능 개선을 위해 운영자가 받습니다.

1. 앱이 기기에서 처리하는 정보

  • 브라우저 정보: 방문 기록, 검색에 따른 방문 정보, 북마크, 열린 탭, 쿠키 및 웹사이트 데이터. 웹 탐색, 탭 복원과 사용자 설정을 위해 사용합니다.
  • 다운로드·미디어 정보: 미디어 주소와 출처, 파일명, 저장 위치, 다운로드 기록, 썸네일·재생 시간·크기 등의 메타데이터. 미디어 감지, 다운로드, 재생, 파일 관리와 중복 다운로드 확인을 위해 사용합니다.
  • 설정·이용 상태: 저장소 설정, 다운로드 잔여 횟수, 프리미엄 구매 상태와 광고 동의 상태 등 기능 제공에 필요한 정보.
  • 사용자 지정 저장소: 네트워크 저장소 주소, 계정명, 저장 경로와 비밀번호 등 사용자가 등록한 연결 정보. 선택한 저장소에 접속할 때 사용합니다.
  • 잠금·클립보드: 사용자가 설정한 PIN·비밀번호의 검증값을 기기에 보관합니다. 생체인증은 Android 인증 결과를 사용하며 앱이 생체정보 원본을 받지 않습니다. 클립보드 URL 확인 기능을 켠 경우 앱 사용 중 URL을 확인해 열기 여부를 안내합니다.

앱은 동의한 실패 URL 제보를 제외하고 방문 URL·미디어 주소를 운영자 서버로 업로드하지 않습니다. 파일명·네트워크 저장소 인증정보를 제보에 포함하거나 방문·다운로드 내역을 광고 요청에 첨부하지 않습니다. 앱 자체 회원가입은 없습니다. 별도로 동의한 이용자의 앱 사용과 다운로드 시작·완료·실패 횟수는 아래의 사용 통계로 집계하며, 여기에 방문·영상 URL이나 파일 내역을 포함하지 않습니다.

2. 웹사이트·검색·외부 저장소

웹사이트 접속, 검색, 썸네일·미디어 수신 및 다운로드 시 해당 웹사이트, 검색 엔진 또는 미디어 제공 서버로 IP 주소, 사용자 에이전트, 요청 내용과 필요한 쿠키·인증정보가 전송될 수 있습니다. 광고 차단 목록을 갱신할 때는 목록 제공 서버에 연결합니다. 각 서비스의 정보 처리는 해당 서비스의 방침에도 따릅니다.

사용자가 지정한 FTP/FTPS 저장소에는 접속에 필요한 인증정보, 선택한 파일 및 관련 경로가 전송됩니다. 다른 앱으로 열기·공유·내보내기를 선택하면 사용자가 선택한 앱이나 저장소에 필요한 정보가 전달됩니다.

3. 광고와 동의 선택

무료 다운로드 이용권을 제공하기 위해 Google AdMob 보상형 광고와 Google의 동의 관리 SDK(UMP)를 사용합니다. 광고 SDK는 광고 제공·측정·부정 사용 방지를 위해 다음 정보를 수집·공유합니다.

  • IP 주소 및 IP에서 추정할 수 있는 대략적인 위치
  • 앱 실행, 광고 조회·탭·동영상 시청 등 앱·광고 상호작용
  • 앱 및 SDK의 성능·진단 정보
  • Android 광고 ID, 앱 세트 ID 및 적용되는 기기·계정 식별자

Google의 광고 서비스와 동의 화면에 표시되는 광고 파트너가 적용되는 설정과 동의 상태에 따라 정보를 처리합니다. 앱은 광고 요청에 사용자의 방문·다운로드 목록을 추가하지 않습니다. 동의 관리가 요구되는 지역에서는 안내 화면이 제공되며, 해당되는 경우 앱 설정의 광고 개인정보 선택에서 선택을 변경할 수 있습니다. 광고 ID는 Android 설정에서 관리할 수 있습니다.

자세한 처리·보관 정보: Google 개인정보처리방침, Google 광고 기술 안내, AdMob SDK 데이터 안내.

3-1. 선택적인 앱 사용 통계

이 기능을 포함한 버전에서는 처음에 별도 동의 안내를 표시합니다. 동의하기 전에는 Firebase Analytics 수집이 꺼져 있습니다. 동의하면 운영자가 Google Firebase Analytics 및 Google 애널리틱스로 일일 활성 사용자와 다운로드 시작·완료·실패 횟수를 확인하여 이용 현황과 다운로드 안정성을 개선합니다. 거절하거나 뒤로가기로 닫아도 앱의 모든 기능을 계속 이용할 수 있습니다.

Google은 임의의 앱 인스턴스 식별자, 앱·기기·운영체제·언어 정보, 앱 실행·세션·참여 이벤트, IP로부터 파생된 대략적인 위치 및 수집 조건에 해당하는 광고·구매 이벤트(예: 상품·금액·통화)를 처리할 수 있습니다. SDK가 수집하는 세부 항목과 처리에는 Google 개인정보처리방침이 적용됩니다. Firebase·Google 애널리틱스·연결된 AdMob 간 이용 및 광고 수익 분석에 활용될 수 있습니다. 미국 등 국외 Google 인프라에서 HTTPS로 처리됩니다.

앱이 추가하는 분석에는 다운로드 시작·완료·실패와 보상형 광고 안내 진입·버튼 선택·동의 처리·준비·표시·닫기·보상 및 서버 확인 단계의 고정된 이벤트 이름만 사용합니다. 실패는 네트워크, 광고 재고 없음, 인증 실패 등 미리 정한 분류로 기록합니다. 페이지·영상 URL, 검색어, 제목, 파일명, 파일 내용, 오류 원문, 쿠키·로그인 정보, 저장소 인증정보 및 광고·이용권 서버의 식별자는 첨부하지 않습니다. 시크릿 탭에서 시작한 다운로드와 시크릿 화면의 광고 과정은 제외합니다. Analytics의 광고 ID·SSAID 수집, 자동 화면 보고 및 광고 개인 최적화는 끄며, 사용자 ID를 별도로 설정하지 않습니다. AdMob 자체의 처리는 위 광고 항목과 별도의 동의 설정을 따릅니다. 임의 식별자를 사용하므로 완전 익명이 아닌 가명 처리된 데이터입니다.

설정의 ‘앱 사용 통계’를 언제든 끄면 이후 분석 수집을 중지하고 기기의 Analytics 식별자와 대기 중인 분석 데이터를 초기화합니다. 이미 Google에 수신된 데이터까지 즉시 삭제하는 것은 아닙니다. Google 애널리틱스의 이벤트 단위 데이터 보관은 2개월, 사용자 데이터 보관은 14개월이며 새로운 사용자 활동이 있으면 사용자 데이터의 보관 기간이 다시 시작됩니다. 합산된 표준 보고서는 이 기간보다 오래 남을 수 있습니다. 개인정보 처리·삭제 문의는 아래 이메일로 할 수 있으며, 개발자가 이름·이메일과 분석 식별자의 대응표를 보관하지 않아 특정 기록을 찾는 데 한계가 있을 수 있습니다.

4. 결제

프리미엄 구매는 Google Play 결제를 사용합니다. 앱은 상품, 구매 상태 및 구매 확인·복원에 필요한 구매 토큰을 처리합니다. 구매 토큰은 기기에 암호화해 보관하고 HTTPS로 검증 서버에 보내 Google Play 구매 조회·확인에 사용합니다. 서버는 구매 토큰 원문을 저장하지 않고 토큰의 해시와 최대 24시간 유효한 프리미엄 확인 상태를 보관합니다. 운영자가 앱에서 카드 번호나 결제 계좌 정보를 직접 받지는 않습니다. 결제·거래 정보의 처리는 Google Play의 정책과 적용 법령에 따릅니다.

5. 권한과 보안

앱 보안과 부정 사용 방지를 위해 Play Integrity API와 Cloudflare Workers 검증 서버를 사용합니다. 이용권 등록, 광고 시청 준비, 구매 확인 및 새 다운로드·재개 시 Google Play Store는 앱의 패키지명·버전·서명, Play 앱 라이선스 상태, 기기 증명 정보와 요청 해시를 처리합니다. 해시는 앱 패키지, 임의 요청 번호·설치 식별자와 해당 작업의 데이터에서 만들며 방문·영상 URL, 파일명, 쿠키, 저장소 인증정보 또는 광고 ID를 포함하지 않습니다.

앱은 무결성 토큰, 임의 설치 식별자, 설치 인증값 및 이용권 작업 정보를 HTTPS로 서버에 전송합니다. 서버는 Google에 토큰 복호화를 요청해 앱·기기 무결성과 Play 설치 라이선스를 확인합니다. 구매 토큰은 Google Play 구매 확인에 별도로 사용합니다. 광고 보상은 Google AdMob이 보내는 서명된 서버 콜백으로 확인한 뒤 1회당 영상 다운로드 이용권 5회를 지급합니다. 설치 식별자와 임의 광고 작업 번호를 이 콜백 연결에 사용하며, SDK의 광고 시청 알림만으로 이용권을 지급하지 않습니다.

서버에는 설치 인증값의 해시, 잔여 이용권, 구매 토큰의 해시·프리미엄 확인 만료 시각, 광고 보상 거래·작업 번호와 다운로드 작업 번호의 차감·완료·환급 상태를 보관합니다. 테스트 접근 인증을 사용한 경우 인증 성공 및 테스트 권한 상태도 보관합니다. 이는 이용권 제공·구매 복원·중복 보상 및 부정 사용 방지에 사용하며 웹사이트 방문·다운로드 목록은 이용권 검증 서버로 보내지 않습니다. 무결성 토큰·복호화 판정·요청 본문과 비밀번호 원문은 서버 로그나 데이터베이스에 보관하지 않습니다. Cloudflare는 연결 IP 및 서비스 정보를 처리하고 서버는 짧은 기간 IP 요청 횟수를 제한합니다. Google과 Cloudflare에는 각 서비스 방침이 적용됩니다. Cloudflare 개인정보처리방침과 Google 개인정보처리방침을 참고하세요.

다운로드 권한 확인에 실패하거나 서버를 이용할 수 없으면 새 다운로드가 시작되지 않으며 재시도할 수 있습니다. 실패·취소 작업의 차감분은 환급하고 연결이 없을 때는 환급 요청을 기기에 보관해 이후 연결 시 다시 처리합니다. 이미 저장한 미디어의 재생·관리는 이 검증을 요구하지 않습니다.

미디어·폴더 접근 권한은 허용된 파일을 표시·저장하고, 알림 권한은 다운로드 상태를 안내하기 위해 사용합니다. 네트워크 상태는 Wi-Fi 다운로드 조건 등에 사용하며, 진동은 사용자가 설정한 미디어 감지·완료 안내에 사용합니다.

네트워크 저장소 비밀번호는 Android Keystore의 키로 암호화하여 기기에 저장합니다. PIN·비밀번호의 검증값은 원문 비밀번호와 구분하여 보관합니다. 앱 잠금과 항목 잠금은 앱을 통한 접근을 제어하는 기능이며, 미디어 파일 자체를 암호화하지 않습니다. 앱의 Android 자동 백업 및 기기 전송은 비활성화되어 있습니다.

HTTP 웹사이트 또는 FTP 저장소의 전송은 암호화되지 않을 수 있습니다. 지원되는 경우 HTTPS·FTPS를 사용하세요. 기기, 외부 저장소와 연결 대상의 접근 권한 및 보안 설정도 데이터 보호에 영향을 줍니다.

6. 보관, 삭제와 사용자 선택

기기에 저장되는 정보는 기능 제공에 필요한 동안 또는 사용자가 삭제할 때까지 보관됩니다. 설정에서 방문·다운로드 기록의 저장 여부를 변경하고 기록·쿠키·웹사이트 데이터를 삭제할 수 있습니다. 다운로드 기록 저장을 꺼도 파일 관리와 진행 중인 다운로드에 필요한 작업·미디어 정보는 남을 수 있습니다. 시크릿 탭은 일반 방문 기록과 탭 복원 목록에 포함하지 않지만, 시크릿 탭에서 사용자가 저장한 파일은 저장 위치에 남습니다.

앱에서 저장한 파일을 삭제할 수 있습니다. 앱 제거 시 앱 내부 데이터는 Android의 제거 동작에 따라 삭제되지만, 미디어 라이브러리·선택한 폴더·네트워크 저장소에 저장한 파일은 남을 수 있으므로 해당 위치에서 별도로 삭제해야 합니다. 웹사이트, Google 및 다른 외부 서비스가 보관하는 정보의 삭제는 각 서비스의 방법을 이용해야 합니다.

서버 이용권 기록은 마지막 서버 활동 후 365일 동안 보관한 뒤 자동 삭제합니다. 앱 삭제·데이터 초기화는 서버 기록을 즉시 삭제하지 않으며 설치 식별자와 인증값을 잃으면 해당 설치의 무료 이용권을 복원할 수 없습니다. 프리미엄 구매는 동일한 Google Play 계정의 구매 복원으로 다시 확인할 수 있습니다. 이용권 정보 처리에 관한 문의는 아래 개인정보 문의 이메일로 보내세요.

7. 안내 웹사이트와 문의

이 웹사이트는 GitHub Pages에서 제공합니다. 별도의 광고, 분석 스크립트, 입력 폼 또는 추적 쿠키를 사용하지 않습니다. GitHub는 사이트 제공·보안을 위해 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. GitHub Pages 접속 정보 안내, GitHub 개인정보처리방침을 참고하세요.

개인정보 문의: GitHub 공개 문의 페이지. GitHub 계정으로 문의를 등록하면 계정명과 문의 내용이 공개됩니다. 운영자는 문의 처리와 답변 이력 관리에 필요한 범위에서 이를 확인·사용하며, 문의 기록은 GitHub에 보관됩니다. 직접 게시한 내용의 수정·삭제 또는 문의 기록의 삭제 요청은 GitHub 기능과 문의 페이지를 이용할 수 있습니다. GitHub가 처리하는 계정·접속 정보에는 GitHub의 방침이 적용됩니다.

공개 문의글에 개인정보, 방문·다운로드 내역, 영상 주소 또는 네트워크 저장소 비밀번호를 올리지 마세요. 앱 기능이나 개인정보 처리에 관한 일반적인 질문은 이런 정보 없이 문의할 수 있습니다.

다운로드 문제 제보 버튼은 외부 브라우저에서 Google 제보 설문지를 엽니다. 이 외부 설문에는 URL, 오류 내용, 국가, 파일, 식별자 또는 진단정보를 사전 입력하거나 자동 첨부하지 않습니다. 이용자가 직접 작성하고 제출한 페이지 URL과 문제 유형, 선택적으로 입력한 오류·재현 설명, 국가, 기기·앱 버전, 건의와 연락 이메일은 Google Forms에 보관됩니다. 운영자는 문제 조사·답변·기능 개선에 필요한 동안만 이를 처리하고, 불필요해지면 삭제합니다. Google 설문지의 응답 요약 공개 기능과 이메일 자동 수집 기능을 사용하지 않으며, 로그인을 요구하지 않습니다. Google 개인정보처리방침도 적용됩니다.

제보 내용의 삭제 요청이나 이메일 문의는 gomeng-dev@protonmail.com으로 보내세요. 직접 보낸 이메일 주소와 문의 내용도 문의 해결에 필요한 동안만 처리하고 불필요해지면 삭제합니다. 이메일 서비스 제공자의 방침도 적용됩니다. 설문이나 이메일에 비밀번호, 쿠키, 인증 토큰 또는 불필요한 개인정보를 포함하지 마세요.

앱 내 실패 URL 제보 — 선택 기능

이 기능을 제공하는 버전에서는 다운로드 실패 시 전송할 URL과 수집 항목을 안내하고 제보 여부를 묻습니다. 제보하기를 누르면 해당 건만 전송합니다. 자동 제보 체크박스를 선택하고 제보하기를 누르거나 설정의 동의 화면에서 활성화하면 이후의 실패도 자동 전송합니다. 기본값은 꺼짐이며 취소·뒤로가기는 동의가 아닙니다. 설정에서 언제든 끌 수 있습니다. 시크릿 탭 다운로드는 제외합니다.

전송 항목은 페이지 URL(없으면 미디어 URL), 정형 오류 코드, 미디어 형식, 앱 버전과 건별 임의 제보 번호입니다. 서버는 접수 시각을 기록합니다. 이름·이메일·파일·쿠키·인증 헤더·설치 식별자·결제 내역은 첨부하지 않으며 광고나 이용권 원장과 결합하지 않습니다. URL의 사용자 정보·프래그먼트·허용하지 않은 쿼리 매개변수를 제거하지만 경로나 남은 값으로 콘텐츠 또는 개인을 추정할 수 있으므로 완전한 익명성을 보장하지 않습니다.

HTTPS로 Cloudflare의 별도 비공개 보관함에 접수하고 운영자 인증을 거쳐 조회합니다. 제보 URL에 서버가 자동 접속하지 않습니다. Cloudflare는 서비스 제공과 오남용 방지를 위해 연결 IP 등을 처리하며, 앱 서버는 IP를 제보 기록에 저장하지 않습니다. 국외 Cloudflare 인프라에서 처리될 수 있습니다. 제보는 접수 후 30일 이내 운영 보관함에서 삭제하고 복구 백업에는 추가 최대 30일간 남을 수 있습니다. 조기 삭제는 위 개인정보 문의 이메일로 제보 URL을 알려 요청할 수 있습니다. 기기의 미전송 안내는 24시간 뒤 만료되며 다음 앱 사용 시 정리합니다. 전송 제한·연결 실패로 접수되지 않을 수 있으며 제보 여부는 다운로드 기능 이용에 영향을 주지 않습니다.
