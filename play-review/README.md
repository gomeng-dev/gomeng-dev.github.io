# Easy Video Downloader foreground service demonstration

[Watch the recording](service-demo.mp4)

This recording uses original synthetic color bars and sine audio in an isolated Android 10 emulator running Easy Video Downloader 1.0.12. It contains no customer browsing or media. Download credits were set only in the demo debug build to prepare the service demonstration; this is not a payment or advertising demo.

- 00:00–00:20: The user selects a detected MKV file and starts the download. The download row identifies the automatic MKV → MP4 conversion.
- 00:20–01:00: The user leaves the app. The notification displays the continuing MP4 conversion. The saved result is a valid 40-second H.264/AAC MP4.
- 01:00–01:30: The user opens the downloaded-video library and selects Export from the file menu.
- 01:30–02:12: The user selects the device media library as the export destination and leaves the app. The export completion notification and both app/private and exported copies are shown.

The recording consists of unmodified consecutive emulator screen captures with their original timing. The emulator's native screenrecord encoder was unavailable. Only a video is hosted here; no downloaded media, credentials, user data, or debug settings are published.
